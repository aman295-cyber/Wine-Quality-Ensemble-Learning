# 🍷 Wine Quality Prediction using Ensemble Learning

## 📌 Project Overview
This project uses Machine Learning classification algorithms to predict whether a wine is of good quality based on its physicochemical properties.

The red and white wine datasets are combined, and wine is classified as **Good Quality (quality ≥ 7)** or **Not Good Quality (quality < 7)**.
### 🍷 Wine Quality Prediction — Ensemble Learning

Machine Learning project that compares multiple classification algorithms and ensemble techniques to predict wine quality.

- **Tech Stack:** Python, Pandas, NumPy, Scikit-learn
- **Models:** Random Forest, Voting, Stacking, SVM, Logistic Regression
- **Best Accuracy:** 88.62% — Random Forest
- **Notebook:** [View Project](https://github.com/aman295-cyber/Wine-Quality-Ensemble-Learning)

## 🎯 Objectives
- Analyze red and white wine quality data.
- Apply multiple Machine Learning classification algorithms.
- Compare model performance using evaluation metrics.
- Explore ensemble learning techniques to improve predictions.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Joblib

## 🤖 Machine Learning Models
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Support Vector Machine (SVM)
- Random Forest
- AdaBoost
- Gradient Boosting
- Voting Classifier
- Stacking Classifier
- Hyperparameter-tuned Random Forest

## 📊 Key Results
- **Best Accuracy:** Random Forest — approximately 88.62%
- **Stacking Classifier:** approximately 85% accuracy, with 80.1% recall for good-quality wine.
- Models were compared using accuracy, precision, recall, F1-score, and confusion matrices.

## 📌 Conclusion
This project compares traditional Machine Learning algorithms and ensemble learning methods for wine quality classification. Random Forest achieved the highest accuracy among the evaluated models, while Stacking showed stronger recall for the good-quality wine class.
